# 📊 Business Performance Dashboard - Power BI

## 📌 Project Overview
This Power BI dashboard provides a complete business performance analysis by visualizing Sales, Profit, Customer Segments, Products, Regions, and Inventory performance.

The dashboard helps business users identify sales trends, top-performing products, customer behavior, and the impact of discounts on profitability.

---

## 🚀 Features

- 📈 Sales Trend Analysis
- 💰 Total Sales & Total Profit KPIs
- 🌍 Region-wise Sales Distribution
- 🛒 Top Performing Products
- 📦 Slow Moving Products
- 👥 Customer Segmentation
- 🔁 Repeat Customer Analysis
- 📉 Discount vs Profit Analysis
- 📅 Quarterly Sales Trend
- 📊 Interactive Filters (Year, Region, Category, Segment)
